BBL GIS IMMO — API Dokumentation

REST API für den programmatischen Zugriff auf das Immobilienportfolio des Bundes

Übersicht

Die BBL GIS IMMO API bietet lesenden Zugriff auf die Gebäude- und Grundstücksdaten des Bundesimmobilienportfolios. Alle Endpunkte liefern GeoJSON-kompatible Antworten.

Base URL :https://api.bbl-immo.admin.ch/v1
Format :GeoJSON (application/geo+json)
Authentifizierung :API-Key via Header X-API-Key
Rate Limit :100 Anfragen / Minute

Endpunkte

GET/buildings

Alle Gebäude als GeoJSON FeatureCollection. Unterstützt Filter via Query-Parameter.

Parameter
adr_landFilterung nach Land (z.B. CH, DE)
adr_regFilterung nach Region/Kanton (z.B. BE)
bbl_statFilterung nach Status (z.B. Aktiv)
bbl_eigenFilterung nach Eigentumsart
bbl_portFilterung nach Teilportfolio
limitMax. Anzahl Ergebnisse (Standard: 100)
offsetPagination Offset
Beispiel
GET /v1/buildings?adr_land=CH&adr_reg=BE&limit=10

HTTP/1.1 200 OK
Content-Type: application/geo+json

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "bbl_id": "1000/4840/AF",
        "bbl_bez": "Bundeshaus West",
        "bbl_stat": "Aktiv",
        "adr_land": "CH",
        "adr_ort": "Bern",
        ...
      },
      "geometry": {
        "type": "Point",
        "coordinates": [7.4441, 46.9465]
      }
    }
  ]
}
GET/buildings/{bbl_id}

Einzelnes Gebäude nach BBL-ID. Gibt ein einzelnes GeoJSON Feature zurück.

Beispiel
GET /v1/buildings/1000%2F4840%2FAF
GET/parcels

Alle Grundstücke als GeoJSON FeatureCollection mit Polygon-Geometrie.

Parameter
adr_landFilterung nach Land
bfs_gemnrFilterung nach BFS Gemeindenummer
bbl_weFilterung nach Wirtschaftseinheit
limitMax. Anzahl Ergebnisse (Standard: 100)
GET/parcels/{bbl_id}

Einzelnes Grundstück nach BBL-ID.

Datenmodell

Die API liefert Attribute gemäss dem BBL GIS IMMO Datenmodell. Alle Feldnamen sind Shapefile-kompatibel (max. 10 Zeichen).

wgs84_lonWGS84 Längengrad

garea_gfGeschossfläche GF in m² (SIA 416)
