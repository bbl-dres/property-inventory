How to get a Client ID

  2. Click "Register new application"
  3. Name: anything (e.g. "Building Heights")
  4. Redirect URI:
  5. Uncheck "Confidential application"
  6. Check "Read user preferences" and "Modify the map"
  7. Click Register, copy the Client ID
